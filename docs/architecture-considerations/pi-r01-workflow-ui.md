# PI Workflow UI — NIH R01

Product/UX spec: proposal workbench (not a chatbot), multi-document R01, visible RBAC, staged submit.

Official NIH submit is an OSPA/AOR action. Do not store eRA passwords. Submission assistant only after institutional approval with the AOR present.

Roles: PI (edit, freeze; Submit disabled), Navigator, OSPA/AOR (approve transmit), Admin (kill-switch).

See also ui-copilotkit/ for the running workbench.
