# Demos

Walkthroughs submit the packet to the **Office of Research Aid database** (intake form → packaging agent → tracking number). There is **no Submit to NIH**.

## 1. CopilotKit Next.js UI (port 3000)

[e2e-copilotkit-demo.mp4](e2e-copilotkit-demo.mp4) — 46s, CopilotSidebar + grouped intake form.

1. Review sample DOCX
2. Intake form (Compliance / Formatting / Institutional) agent-filled
3. PI overrides remaining unknowns and certifies
4. **Submit to Office of Research Aid**
5. Tracking number returned to the PI
